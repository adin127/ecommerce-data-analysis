# E-Commerce Data Analysis
An end-to-end data analytics project that analyzes e-commerce sales performance, customer activity, product performance, payment methods, and shipment status using Python, PostgreSQL, SQL, and Power BI.

## 📌 Project Overview
This project demonstrates an end-to-end data analytics workflow, starting from synthetic e-commerce data generation and relational database management to SQL-based analysis and interactive business intelligence visualization.

The project focuses on transforming transactional data into meaningful business insights that can support sales monitoring, performance evaluation, and data-driven decision-making.

### Key Areas of Analysis
- Sales and revenue performance
- Monthly revenue trends
- Product performance
- Category performance
- Seller performance
- Payment method distribution
- Shipment status
- Customer and order activity
- Average Order Value (AOV)

## 🎯 Business Questions

The analysis was designed to answer several business questions:
1. How is e-commerce revenue trending each month?
2. Which products do customers buy the most?
3. Which sellers contribute the most revenue?
4. Which products have the highest sales revenue?
5. What payment methods are most frequently used?
6. What is the distribution of shipment statuses?
7. What is the average order value?

## 🗂️ Dataset

The dataset represents a simulated e-commerce business and was generated using Python. The database contains the following main entities:

| Table | Description |
|---|---|
| `categories` | Product category information |
| `customers` | Customer information |
| `sellers` | Seller information |
| `products` | Product information |
| `orders` | Order-level transaction information |
| `order items` | Products included in each order |
| `payments` | Payment information |
| `shipments` | Shipment and delivery information |

> Note: The dataset is synthetic and created for portfolio and learning purposes.
